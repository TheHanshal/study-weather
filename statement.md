# Study Weather — Project Statement

## 1. Problem Statement

Students often need to manage study time while also keeping track of their daily activities and surroundings. Managing study sessions and maintaining simple daily records separately can be inconvenient. **Study Weather** provides a single command-line application for managing study sessions and recording daily weather information.

## 2. Scope of the Project

The project focuses on a simple, menu-driven Python application that:

- Provides a customizable Pomodoro study timer.
- Records daily weather, temperature, and notes.
- Displays a weather diary.
- Calculates basic study statistics.
- Provides a summary of the current day's study and weather information.

The project currently stores data in memory during program execution and does not include permanent database or file storage.

## 3. Target Users

The application is primarily intended for:

- **Students** who want to manage study sessions.
- **Learners** who use the Pomodoro technique.
- **Users** who want to maintain a simple daily weather diary.
- **Beginners** interested in a basic command-line productivity application.

## 4. High-Level Features

- 🍅 **Pomodoro Study Timer** — customizable study and break durations.
- 🌤️ **Weather Recording** — record temperature, weather condition, and notes.
- 📖 **Weather Diary** — view recorded weather entries.
- 📊 **Study Statistics** — view sessions, total study time, and average session length.
- 📅 **Today's Summary** — view combined study and weather information for the current day.
- 🚪 **Menu-Based Interface** — access all features through a simple command-line menu.
